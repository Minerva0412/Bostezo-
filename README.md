Bostezo-
Espacio para explorar el bostezo y por qué es contagioso.
Sobre el proyecto
Este repositorio reúne información sobre el bostezo: qué es, qué ocurre en el cuerpo cuando bostezamos y por qué se contagia entre personas.
Contenido
•	¿Qué es el bostezo? Una inhalación profunda y prolongada, seguida de una exhalación, que suele acompañarse de estiramiento.
•	¿Por qué es contagioso? Se relaciona con las neuronas espejo y la empatía: ver, oír o incluso leer sobre un bostezo puede desencadenarlo.
•	Funciones propuestas: regular la temperatura cerebral, aumentar el estado de alerta y sincronizar la atención del grupo.
